# FINANZA — Consultoría Financiera

Aplicación web responsiva desarrollada con HTML, CSS, JavaScript y Bootstrap 5.3.

## Estructura

- `index.html` — estructura principal.
- `css/style.css` — estilos e identidad visual.
- `js/script.js` — interacciones, validaciones, API REST y formulario.
- `aviso-privacidad.html` — Aviso de Privacidad Integral y procedimiento ARCO.
- `terminos-uso.html` — Términos y Condiciones de Uso del sitio.
- `assets/images/` — imágenes del proyecto.

## Ejecutar localmente

Abre `index.html` en un navegador moderno o utiliza Live Server desde VS Code.

## Servicios externos

- Bootstrap 5.3 mediante CDN.
- Google Fonts.
- Hub Fiscal MX para UMA, FIX histórico, INPC y calendario fiscal.
- Web3Forms para recibir las solicitudes del formulario por correo.

## Nota legal

Antes de publicar el sitio, sustituye en `aviso-privacidad.html` los marcadores `[NOMBRE COMPLETO DEL RESPONSABLE]` y `[DOMICILIO DEL RESPONSABLE]` por los datos reales del responsable. No uses datos ficticios.

## Nota

Las imágenes y archivos incluidos en este paquete corresponden a la versión de entrega preparada del proyecto. Evita introducir información bancaria, contraseñas o datos financieros sensibles en el formulario de contacto.
